# ProCoaching — концепт редизайна

Концепт нового дизайна для [procoachingmc.ru](https://procoachingmc.ru): плоские цвета вместо градиентов и свечения, крупная типографика, свои пиксельные иконки режимов.

Один файл `index.html` без сборки, шрифты лежат в `fonts/` (Unbounded и Golos Text, лицензия OFL).

Страницы (роутинг через `#`):
- `#/` — главная: hero, статистика, 12 режимов, блок Screenshare
- `#/mode/<id>` — тренеры режима: фильтры, поиск, сортировка (данные заполнены для Creeper)
- `#/screenshare` — проверяющие

Тексты, цены и ники взяты с текущего сайта. Вход и кнопки «Профиль»/«Подробнее» в концепте не работают.
